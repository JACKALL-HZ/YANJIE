## 1. 项目概述

AI 决策推演工作台——覆盖"拆解→建模→推演→对比→风险→行动→复盘→校准"全周期。

- **阶段**：MVP-0 转 MVP-1（纯后端已闭环，前端 + SSE + DB 已通）
- **技术栈**：Python 3.12 + FastAPI + LangGraph + LangChain + SQLite + Vue 3 + Pinia
- **LLM**：Qwen-Plus via DashScope（`dashscope.aliyuncs.com/compatible-mode/v1`）
- **Embedding**：bge-m3 via SiliconFlow API
- **搜索**：Tavily Search API

## 4. 推演核心流程

```
用户点击启动
  → POST /api/simulations/stream (SSE)
  → SimulationEngine.iter_events()
  → 每年循环：
      1. AgentCoordinator.observe() → RAG + Tavily 搜索
      2. 4 Agent + Judge → LangGraph 内层图（observe→propose→judge→revise→validate→emit）
      3. 外层图 apply_actions → check_ending → append_year
      4. 干预判定（intervention_graph）
      5. 若 PAUSE_EACH_YEAR=1 → yield SIMULATION_PAUSED → 等待用户
      6. 否则继续下一年
  → 结局判定（bankrupt/goal_reached/steady_state/timeout）
  → 评分 + 风险 + 行动计划
```

**逐年交互流程**：
```
Year N 完成 → SSE 发 SIMULATION_PAUSED → 前端显示 "第 N 年完成，请输入决策"
用户输入 → POST /{sessionId}/resume {choice: "用户消息"}
  → resume_events() → Year N+1 开始 → PAUSE_EACH_YEAR 检查 → 暂停/继续
```

## 7. 关键代码路径（快速定位）

- **推演开始**：`SimView.vue:start()` → `simulation.ts:start()` → `sse.ts:streamSimulation()` → `POST /api/simulations/stream`
- **逐年暂停恢复**：`SimView.vue:handleUserSend()` → `POST /api/simulations/{id}/resume` → `engine.py:resume_events()`
- **追问**：`SimView.vue:handleUserSend()` → `sse.ts:streamAsk()` → `POST /api/simulations/{id}/ask/stream` → `ask_service.py:ask_stream_sync()`
- **Agent LLM 调用**：`engine.py:_advance_year()` → `coordinator.propose()` → `inner_graph.py` → `llm_agent.py:propose()` → `self.llm.invoke()`
- **结局判定**：`graph.py:_check()` → `nodes.py:check_ending()` → `ending.py:judge_ending()`

## 8. 注意事项 & 雷区

1. **`.env` 不能随意提交** — 含 API Key，.gitignore 已排除
2. **`LLM_USE_STUB=0` 会烧 token** — 每次推演每年 5 次 LLM API 调用（4 Agent + 1 Judge），调试时务必设 1
3. **前端 `client.ts` 的 401 跳转** — `/auth/me` 返回 401 不跳转，其他端点携带过期 token 会跳 `/login`
4. **SSE 端点不能用 `Depends(get_current_user)`** — 必须用 `get_optional_user`，否则未登录用户无法推演
5. **`PAUSE_EACH_YEAR` 在两个地方检查** — `iter_events`（首轮）和 `resume_events`（恢复），两处必须同步
6. **`user_message` 消费后必须清空** — 否则同一条消息泄漏到后续所有年份
7. **DashScope 的 OpenAI 兼容端点** — `stream()` 方法可能不兼容，追问已改用 `invoke()` 逐字输出
8. **`SIMULATION_EVENT_DELAY_MS`** — 设 >0 会让 SSE 事件间延迟，设太大（500ms）可能触发前端 30s 超时
