# 衍界 YanJie AI · 前端交付说明（2026-08-03）

## 交付范围
Vue3 + TS + Tailwind + Pinia + Vue Router 前端工程（`frontend/`），对接后端 20 端点。

## 页面（8 个，全部完成）
| 路由 | 页面 | 说明 |
|---|---|---|
| `/` | Landing | 视频 Hero（H.264 转码版地球升起 8s loop + poster 兜底）+ 打字机 slogan「让每一个选择都有回响」+ ScrollVelocity 滚动 marquee + 三大支柱 + CTA |
| `/library` | 场景库 | GET /api/scenarios 驱动，液态玻璃卡片 + **素材库氛围图** + spotlight hover + 骨架屏/错误/空三态 |
| `/sim/:scenarioId?` | 推演主界面 | 参数表单 → POST /stream SSE 流式；**ShipLoader 飞船飞入加载**；世界状态面板、时间线、干预卡、终局；ECharts 走势图 + Three.js 3D 分支时间线 |
| `/compare` | A/B 对比 | 双参数表单 → POST /compare → 并排评分卡 + 逐年对照表 + comparison 差异分析 |

| `/diary` | 决策日记 | GET /api/diary + 编辑（tags/notes/archived）+ 现实校准（calibration） |

## 全局视觉
- **v2 Galaxy 背景**：`App.vue` 全局挂载 `AppBackground`（WebGL 星图 + atmos 双色光斑 + grain 噪点），路由 `meta.hideBackground` 排除 Landing 主页，其余 7 页统一生效。
- **素材库图片接入**：6 张素材规范化后进入 `public/assets/img/`，4 张用作场景卡片氛围底，Aetheris 飞船图用作推演加载页氛围，宇航员图用作个人画像页氛围。

## 核心组件（去 AI 感）
- `FancyButton`：素材库 3D 按压按钮深色科技风改造，纯 CSS 多层 inset shadow
- `ScrollVelocity`：reactbits scroll-velocity 的 Vue3 移植（rAF + 弹簧阻尼，滚动越快滑得越快）
- `GlassPanel`：液态玻璃 + 鼠标 spotlight 边框光
- `TypewriterText`：打字机 + 闪烁光标
- `ParticleField`：零依赖 Canvas 星尘（移动端降密度，reduced-motion 静态化）
- `ShipLoader`：飞船从屏幕外飞入 + 引擎粒子喷射 + 旋转进度环 + 全息流体氛围底（reduced-motion 静态化）
- `AppBackground / GalaxyBackground`：v2 稿 WebGL 星图全局背景
- `SkeletonCard / WorldStatePanel / TimelineTrack / InterventionCard / ResultPanel`

## 关键技术决策
1. **视频背景**：素材 video.mp4 为 HEVC(hvc1) 编码，浏览器兼容性差 → 已转码 H.264 yuv420p + faststart（4.1MB，CRF 28），附 poster 帧兜底。路径 `public/assets/videos/hero-earth.mp4`。
2. **SSE 解析**：后端发标准三行 SSE（id/event/data），fetch + ReadableStream 按 `\n\n` 切帧、逐行取 `data:`，POST 流式（EventSource 不支持 POST）。
3. **干预链路**：`intervention.pending` 暂停 → 用户选 option → POST `/simulations/{id}/resume`（同步返回完整 SimulationResponse）→ `applyResponse` 合并时间线 + 终局。
4. **代理**：vite dev server `/api → 127.0.0.1:8000`。

## 响应式 / 无障碍
- 移动 ≥360px：网格折叠、按钮纵排、导航收缩、粒子降密
- `prefers-reduced-motion`：打字机/粒子/marquee 全降级
- focus-visible 环、aria-busy、键盘 Enter 触发卡片

## 验证
- `npm run build`：vue-tsc + vite 零错误；首屏 gzip ~43KB（不含视频/图片）
- 冒烟：后端 8000 + 前端 5173 双起；8 页面路由全 200；GET /api/scenarios 200；SSE 全流程事件齐
- 构建产物校验：SimView chunk 含 ShipLoader；LibraryView chunk 含全部 4 场景配图路径；index chunk 含 AppBackground 全局挂载与 hideBackground 路由标记

## 登录注册（2026-08-03 已完成）
完整 JWT 认证链路，前端路由守卫（全站除首页外需登录）。

**后端**
- `app/db/models.py`：User 表新增 `password_hash`（bcrypt）；`app/db/session.py` 的 `init_db()` 加幂等迁移 `_migrate()`（ALTER 补列，兼容已存在库）
- `app/core/security.py`：bcrypt 原生 `hash_password`/`verify_password`（>72 字节截断，防御 bcrypt 限制）
- `app/core/jwt.py`：HS256 签发/校验，`JWT_SECRET`(来自 .env) + `ACCESS_TOKEN_EXPIRE_MINUTES`(默认 7 天)
- `app/api/auth.py`：POST /api/auth/register（用户名+可选邮箱+密码，3-32 字符用户名、8-128 密码、邮箱格式校验）、POST /api/auth/login（identifier 支持用户名/邮箱）、GET /api/auth/me（需 Bearer）
- `app/api/dependencies.py`：`get_current_user` 从 Authorization 头解 JWT→查用户
- `app/main.py`：注册 auth_router；新增 `HTTPException` 统一错误处理器（转成 `{code,message,request_id}`，与项目一致）
- 错误码：409 USERNAME_TAKEN/EMAIL_TAKEN、401 INVALID_CREDENTIALS、422 INVALID_REQUEST
- 测试：`tests/test_auth.py`（11 用例全绿）；`tests/conftest.py` 改为内存 SQLite 隔离，不再污染业务库 yanjie_dev.db
- 依赖：pyproject 新增 `bcrypt`、`pyjwt`（移除未用的 passlib）

**前端**
- `src/api/types.ts`：AuthUser/AuthToken/RegisterPayload/LoginPayload
- `src/api/auth.ts`：register/login/me
- `src/api/client.ts`：请求自动带 `Authorization: Bearer <token>`（localStorage `yanjie_token`）；401 清 token 跳 /login
- `src/stores/auth.ts`：Pinia store，token+user 持久化 localStorage，login/register/logout/loadMe
- `src/router/index.ts`：除 landing 外所有路由 `meta.requiresAuth: true`；`/login`、`/register` 路由；`beforeEach` 守卫（无 token→/login?redirect，已登录访问登录页→首页）
- `src/views/LoginView.vue` / `RegisterView.vue`：GlassPanel + FancyButton 表单，复用全局 Galaxy 背景
- `src/components/layout/NavBar.vue`：登录态显示用户名 + 退出；未登录显示登录/注册入口
- `src/App.vue`：onMounted 调 `auth.loadMe()` 刷新用户态
