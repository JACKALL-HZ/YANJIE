# AI 决策推演工作台 · 前端视觉增强技术方案

> 技术栈：Vue3 + TypeScript + Tailwind CSS + Three.js  
> 风格定位：深色未来风 · 液态玻璃 · 霓虹辉光  
> 优先级策略：低成本高收益 → 进阶质感 → 极致特效

---

## 一、P0 核心增强（无缝接入，快速拉满质感）

与现有技术栈 100% 兼容，开发成本低，视觉提升最直观。

### 1. Tailwind 生态插件（动效 + 玻璃拟态）

- **tailwindcss-animate**  
  内置入场、脉冲、滑入、渐隐等常用动效类，与 Tailwind 原生语法完全一致，可快速给卡片、按钮、时间线节点添加统一的过渡动效，无需手写大量 CSS。

- **自定义 glassmorphism 工具集**  
  基于 `backdrop-filter: blur()` 扩展一套玻璃拟态样式规范（半透明白边、背景模糊、内层微光、投影分层），统一应用在面板、弹窗、侧边栏，完美契合深色科技主题，实现液态玻璃高级质感。

**适配场景**：所有信息卡片、功能面板、弹窗、侧边导航。

### 2. VueUse + VueUse Motion

基于 Vue 响应式的声明式动效库，轻量无侵入，用组合式 API 即可实现元素入场、滚动触发、状态切换动效，比原生 CSS 动画更灵活，且完全贴合 `<script setup>` 开发习惯。

**适配场景**：时间线节点点亮、数据面板滑入、数值变化平滑过渡、列表元素序列入场。

### 3. Three.js 后处理库 postprocessing

给现有 3D 分支时间线增加 **Bloom 泛光**、景深、轻微胶片颗粒效果，让 3D 节点和连线自带霓虹辉光，质感直接从「普通 3D 模型」升级到「电影级渲染」，与参考图的玻璃星光效质感对齐。

**适配场景**：SimView 主界面的 3D 时间线可视化核心区域。

## 二、P1 进阶动效与可视化（强化交互沉浸感）

在基础质感之上，优化页面流转与数据展示的华丽度，兼顾实用性与视觉表现。

### 1. GSAP (GreenSock) 专业动效库

行业级动效编排工具，支持时间线序列动画、自定义缓动曲线、物理动效，可精准控制多元素的动效节奏，是高端科技产品的标配。

**适配场景**：
- 模拟推演启动时的整体序列动效（面板依次展开、时间线逐节点点亮）
- 路由页面切换过渡
- 拖拽交互反馈
- 数据面板展开收起

**优势**：比 CSS 动画上限高得多，能做出带有「叙事感」的丝滑动效，大幅提升产品的专业度与高级感。

### 2. Apache ECharts（深色辉光主题）

专业数据可视化库，可深度定制深色主题下的发光折线、雷达图、热力图、仪表盘，自带平滑动画与交互反馈。

**适配场景**：评分面板、风险趋势图、个人画像数据看板、A/B 对比页的多维度数据对比。

**优势**：替代纯表格展示，信息传达效率更高，且深色 + 辉光的样式与整体科技风高度统一。

### 3. tsparticles 粒子系统

轻量 Canvas 粒子库，低性能损耗，可定制背景微光粒子、节点爆炸粒子、过渡粒子效果。

**适配场景**：
- 首页 / 登录页背景
- 推演完成的庆祝动效
- 风险预警的粒子提示
- 场景卡片 hover 微光反馈

**优势**：不干扰核心内容的前提下，大幅提升页面氛围感与科技质感。

## 三、P2 极致特效与细节打磨（追求顶级视觉表现）

适合 MVP 功能闭环后做视觉升级，打造差异化的高级感。

### 1. TresJS（Vue3 声明式 Three.js 封装）

Vue3 原生的 Three.js 声明式框架，与 `<script setup>` 语法完美契合，自带大量预设材质、几何体、后处理能力，比原生 Three.js 开发效率提升 3 倍以上。

**适配场景**：重构 3D 时间线，加入玻璃质感节点、流动光效连线、视角切换动效，支持用户自由旋转、缩放、点击节点查看详情。

### 2. 自定义 Shader 特效

基于 WebGL/Canvas 编写自定义着色器，实现流动流体背景、光标跟随光晕、卡片边缘流光、文字渐变扫光等定制化效果。

**适配场景**：
- 首页标题动效
- 卡片 hover 边界光
- 推演进行中的背景流体动效
- 关键数据的流光强调

**优势**：完全定制化的视觉效果，是高端定制产品与普通模板产品的核心区别。

### 3. @antv/G6 关系图谱

专业图可视化引擎，支持交互式拓扑图、力导向图，可定制节点样式与连线流动动效。

**适配场景**：多 Agent 决策链路可视化、分支时间线的关系拓扑、干预节点的影响路径展示。

### 4. 微交互细节组件

- **打字机效果组件**：SSE 流式输出 Agent 思考内容时，逐字呈现的打字机动效，搭配闪烁光标，提升 AI 交互沉浸感。
- **骨架屏组件**：使用 `vue-content-loader`，加载时显示与内容结构一致的渐变扫光骨架，替代生硬的加载转圈。
- **自定义光标体系**：推演状态下切换专属光标样式，hover 交互元素带光晕反馈，强化全局科技感。

## 四、设计系统配套（保证华丽但不杂乱）

所有视觉增强都需要统一规范，避免动效与样式混乱：

| 维度 | 建议方案 |
|------|----------|
| **统一设计语言** | 扩展 Tailwind 主题，定义固定的「辉光强度」「模糊半径」「配色体系」（主色深空蓝 + 霓虹青 / 紫点缀），所有动效时长统一为 200ms / 300ms / 500ms 三档 |
| **字体层级优化** | 正文用 Inter 无衬线字体保证可读性，标题与关键数据搭配 JetBrains Mono 等宽字体，强化科技属性 |
| **主题系统** | 基于 CSS 变量实现明暗主题切换，可扩展「推演模式」「分析模式」等不同场景的主题配色 |

---

**推荐落地顺序**：优先完成 P0 → 验证视觉提升效果 → 再推进 P1 → MVP 闭环后视需求启动 P2。
