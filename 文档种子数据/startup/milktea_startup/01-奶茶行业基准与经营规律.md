# 奶茶行业基准数据与经营规律

> 适用场景：创业模拟 · 奶茶店 / 新式茶饮  
> 知识类型：industry_benchmark  
> 覆盖城市：全国通用 + 杭州/二线商圈补充  
> 更新参考：公开行业报告与连锁公开披露数据（模拟用，非投资建议）

---

## 1. 行业定位与周期

新式茶饮（含现制奶茶、果茶、轻食茶饮）在中国已从高速扩张期进入**存量竞争与分化期**。头部品牌靠供应链与加盟体系抢份额，中小单店依赖选址、产品差异化与精细运营求存。

典型周期特征：
- **导入期（0–6 个月）**：获客成本高、复购未形成，多数门店处于亏损或微利边缘。
- **爬坡期（6–18 个月）**：若选址与产品过关，客流与复购逐步稳定，毛利可支撑租金与人工。
- **稳态或衰退（18 个月后）**：要么形成稳定现金流，要么被同商圈竞品与成本上涨挤压，进入收缩或关店决策窗口。

模拟推演时，建议将「回本周期」与「月利润是否连续达标」作为结局判定的核心指标，而不是单一「开业即盈利」。

## 2. 关键财务基准（单店）

以下为**二线城市核心商圈 / 社区型铺位**的常见区间，用于决策源 industry_benchmarks 与 Agent 约束，非精确预测。

| 指标 | 常见区间 | 说明 |
|------|----------|------|
| 客单价 | 12–22 元 | 下沉市场偏低，高端茶饮/大杯化偏高 |
| 日均杯量（稳态） | 150–350 杯 | 强依赖选址与时段；旺季可上浮 30%+ |
| 毛利率（扣原料） | 55%–65% | 含杯具、配料；果茶季节波动大 |
| 租金占营收比 | 15%–25% | 超过 30% 极难持续 |
| 人工占营收比 | 18%–28% | 含社保与排班冗余 |
| 回本周期 | 8–18 个月 | 预算 15–30 万量级单店常见区间 |
| 盈亏平衡日杯量 | 约 120–180 杯 | 视租金与人工结构而定 |

杭州等消费力较强的二线城市，客单价与租金均偏高一档：客单价常落在 15–25 元，核心商圈租金占比更容易顶到 22%–28%。

## 3. 成本结构拆解

单店月成本大致可分为：

1. **固定成本**  
   - 租金、物业、基础水电、基础工资（店长+1～2 名全职）。  
   - 特点：不随杯量线性下降，是「现金流断裂」的主要压力源。

2. **变动成本**  
   - 原料、杯盖吸管、包装、部分提成或兼职工时。  
   - 毛利率主要由此决定；原料损耗与过期是隐形杀手。

3. **半固定 / 营销成本**  
   - 外卖平台抽成（通常 15%–25% 订单金额）、地推、社群、会员优惠。  
   - 过度依赖外卖会进一步压缩净利。

经验规则：  
- 若「租金 + 人工」长期超过营收 45%，即使毛利 60% 也极易陷入持续亏损。  
- 开业前 3 个月应单独做「获客预算」，避免把全部现金压在装修与设备上。

## 4. 选址与商圈类型

| 商圈类型 | 客流特点 | 适合产品 | 主要风险 |
|----------|----------|----------|----------|
| 核心商圈 / 购物中心 | 高人流、高租金 | 标准化、高辨识度 | 租金与竞品密度双高 |
| 社区底商 | 复购稳定、租金可控 | 性价比、会员制 | 辐射半径有限，增长天花板低 |
| 写字楼 / 产业园 | 工作日午餐+下午茶 | 快取、轻食组合 | 周末与节假日断崖 |
| 大学城 | 年轻客群、价格敏感 | 大杯、联名、活动 | 寒暑假与毕业季波动 |

选址错误是奶茶店前 12 个月关店的最常见主因之一。模拟中「城市 + 商圈类型」应作为决策变量，并影响环境 Agent 与市场 Agent 的基准参数。

---

## 5. 竞争与定价规律

- 同一商圈步行 500 米内若已有 3 家以上同类茶饮，新店获客成本显著上升。  
- 价格战可短期拉升杯量，但会破坏毛利与品牌心智；差异化（口味、场景、会员权益）比单纯降价更可持续。  
- 头部连锁的供应链与营销预算对单店形成「降维」压力：单店更适合打「局部密度 + 复购」而非全国知名度。

市场 Agent 决策时，可将「商圈竞争密度」「是否价格战」「是否差异化」作为可选行动，并回写到世界状态（竞争数、客单价、客流）。

## 6. 经营节奏与关键节点

年度推演中可关注的典型节点：

- **第 1–3 个月**：装修尾款、试营业、首批会员沉淀；现金流最紧。  
- **第 4–6 个月**：是否形成稳定复购；若日杯量仍低于盈亏平衡，需决策「加码营销 / 降本 / 止损」。  
- **第 7–12 个月**：首次设备维护、原料涨价或竞品新店开业窗口。  
- **第 13–24 个月**：是否考虑第二店、还是巩固单店利润。  
- **第 25–36 个月**：租约到期、消费趋势变化、品类是否过时。

风险 Agent 可基于「现金流阈值」「竞争数阈值」「连续亏损月数」触发关键事件，供用户干预。

## 7. 模拟用简化公式（参考）

以下为决策源或引擎可用的简化关系（非精确财务模型）：

- 月营收 ≈ 日均杯量 × 客单价 × 30  
- 月毛利 ≈ 月营收 × 毛利率  
- 月净利粗估 ≈ 月毛利 − 租金 − 人工 − 其他固定 − 外卖抽成等  
- 回本进度 ≈ 累计净利 / 初始投入  

当累计净利 ≥ 初始投入时，可判定「回本」类目标达成；当现金流连续低于设定阈值，可触发「现金流告急」干预事件。
