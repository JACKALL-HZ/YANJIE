# 决策框架：SWOT 与波特五力（茶饮单店）

> 适用场景：决策拆解助手 · 处境建模 · 多方案对比说明  
> 知识类型：framework  
> 用途：帮助把模糊念头结构化；不直接输出「该不该干」的结论

---

## 1. SWOT（单店创业视角）

### 优势（Strengths）可能来源

- 创始人具备餐饮或零售经验、本地人脉。  
- 预算含足够运营缓冲，租约条款灵活。  
- 产品有明确差异点（配方、场景、供应链）。  
- 可全职投入，决策链条短。

### 劣势（Weaknesses）常见项

- 无品牌与供应链优势，获客依赖地推与平台。  
- 个人精力与管理半径有限。  
- 对选址与成本模型缺少量化验证。  
- 合伙权责不清。

### 机会（Opportunities）

- 特定商圈仍存在供给空白或品质缺口。  
- 会员与私域工具降低获客成本。  
- 健康化、分段甜度、办公场景等趋势可产品化。  
- 地方消费促进政策的短期流量。

### 威胁（Threats）

- 头部品牌与现有密集供给。  
- 租金与人工上涨。  
- 平台规则与抽成变化。  
- 食安舆情与同质化价格战。

**使用方式**：决策拆解阶段可用 SWOT 四格组织用户输入；推演中市场/环境/个人/风险四个 Agent 大致分别强化 O/T 与 S/W 的动态变化。

## 2. 波特五力（茶饮单店层）

### 2.1 现有竞争者之间的竞争 — 强

门店密度高、产品易模仿、消费者切换成本低。单店策略应避免在同一商圈与多家门店进行纯价格消耗战。

### 2.2 潜在进入者威胁 — 中高

开店资金门槛相对可控，导致不断有新进入者；但证照、选址与运营能力构成软门槛。环境与政策若提高合规成本，会抑制部分进入。

### 2.3 替代品威胁 — 中

咖啡、便利店饮料、家里自制、其他甜品与休闲场景都会分流「下午茶时段」预算。差异化体验与习惯养成（会员）可降低被替代概率。

### 2.4 供应商议价能力 — 中

大宗原料有多供方，但优质茶叶/乳品/包材在小批量采购时价高；账期短。联合采购或绑定稳定经销商可改善。

### 2.5 买方议价能力 — 强

消费者信息充分、比价容易、对 sweeteners 与成分敏感。提升转换成本（会员积分、习惯口味、到店社交属性）是单店可行路径。

## 3. 与五维评分的对应（产品内）

| 框架视角 | 可映射的产品维度 |
|----------|------------------|
| 市场机会与竞争 | 市场可行性 |
| 租金/人工/预算 | 资源充裕度 |
| 证照与地方政策 | 政策友好度 |
| 五力中的威胁与案例库 | 风险抵御 |
| 现金流与回本 | 财务/结局相关指标 |

多方案对比时，可用同一框架解释「为何方案 A 风险高但成长高、方案 B 相反」，保持评分口径一致。

---

## 4. 决策拆解提示词可引用的结构化输出

当用户只说「我想辞职开奶茶店」时，助手可拆出：

- 决策类型：机会型 / 风险型（取决于是否辞职、预算占比）  
- 变量：预算、城市、商圈类型、是否全职、目标回本周期、成功定义  
- 初步 SWOT 问句：你的经验？缓冲金几个月？目标客群？能否接受最坏关店？
