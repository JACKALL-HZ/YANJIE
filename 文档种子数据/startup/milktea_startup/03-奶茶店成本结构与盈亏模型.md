# 奶茶店成本结构与盈亏模型

> 适用场景：创业模拟 · 财务约束与个人 Agent 决策  
> 知识类型：financial_model / framework  
> 用途：支撑盈亏平衡测算、行动计划中的「成本模型」条目、可行性评分中的资源维度

---

## 1. 初始投入构成（单店参考）

以预算 **15–30 万** 的二线城市社区或次级商圈店为例：

| 项目 | 占比参考 | 说明 |
|------|----------|------|
| 转让费 / 空铺中介 | 0%–25% | 热门铺位可能显著更高 |
| 装修与水电改造 | 25%–40% | 含基础形象与后厨合规 |
| 设备（制冰、封口、冷藏等） | 15%–25% | 可考虑二手以降低门槛 |
| 首批原料与包材 | 5%–10% | |
| 证照、设计、杂费 | 3%–8% | |
| **运营缓冲金（强烈建议）** | **15%–25%** | 覆盖前 3–6 个月可能亏损 |

常见错误：把几乎全部预算花在「看得见的装修」，缓冲金不足，导致尚未验证产品与选址就因现金断裂退出。

## 2. 月度成本分类

### 2.1 固定成本（与杯量弱相关）

- 租金与物业  
- 全职基础工资与社保  
- 基础水电、宽带、软件订阅  
- 贷款利息（若有）

### 2.2 变动成本（与杯量强相关）

- 茶叶、奶、糖、水果、小料  
- 杯、盖、吸管、包装袋  
- 按单提成或高峰兼职

### 2.3 渠道与营销

- 外卖平台佣金与推广  
- 地推物料、社群红包、开业活动  
- 会员折扣的实质让利

---

## 3. 毛利率与净利率

- **毛利率**（扣直接原料与包材）：新式茶饮常见 **55%–65%**。  
- **净利率**（扣租金、人工、水电、营销等）：稳态健康单店多在 **8%–18%**；低于 5% 时抗风险能力很弱。

影响因素：
- 果茶季节与损耗会拉低毛利。  
- 大杯化、高价 SKU 可拉高客单价，但需匹配支付意愿。  
- 外卖占比过高会同时打击毛利与净利。

---

## 4. 盈亏平衡粗算

### 4.1 日盈亏平衡杯量（简化）

设：
- 日固定成本摊销 = 月固定成本 / 30  
- 单杯边际贡献 = 客单价 × 毛利率 − 单杯变动营销等  

则：

**盈亏平衡日杯量 ≈ 日固定成本摊销 / 单杯边际贡献**

示例（仅演示）：
- 月租金 1.2 万，人工 1.0 万，其他固定 0.3 万 → 月固定 2.5 万 → 日固定约 833 元  
- 客单价 16 元，毛利率 60% → 单杯毛利 9.6 元；再扣少量变动营销后按 8.5 元计  
- 盈亏平衡日杯量 ≈ 833 / 8.5 ≈ **98 杯**（实际通常更高，因还有损耗与波动）

模拟中可将「盈亏平衡杯量」写入决策源或世界状态，供个人 Agent 与风险 Agent 使用。

### 4.2 回本周期粗算

**回本月数 ≈ 初始投入 / 月均净利**（需在已过导入期、出现稳定净利后估算）

若前 6 个月为亏损，回本周期应把亏损累计加回投入再除以稳态月净利。

## 5. 现金流比利润更致命

利润是会计结果，**现金流**是生存条件：

- 押金、预付租金、备货会占用现金。  
- 供应商账期长短直接影响周转。  
- 连续 2–3 个月经营性现金流为负，即使「账面未破产」也可能被迫关店。

风险规则示例：
- 当世界状态中 `cash < 阈值`（如 5 万）时，触发「现金流告急」关键事件。  
- 选项可包括：继续投入（需有资金来源）、降本裁员、止损退出。

## 6. 个人 Agent 决策约束建议

个人 Agent 在「投入 / 节省 / 借贷 / 止损」等行动上应受以下约束：

1. **画像约束**：资产有限、有家庭负担、风险偏好保守时，降低「借贷扩张」权重。  
2. **阶段约束**：未达盈亏平衡前，优先「验证与降本」，而非「开分店」。  
3. **缓冲约束**：现金缓冲低于 2 个月固定成本时，强制提高止损与降本选项的优先级。

## 7. 30 天行动计划中的财务条目示例

生成行动计划时可落地的具体条目（禁止空话）：

1. 列出全部月固定成本清单，算出「不卖一杯也要花的钱」。  
2. 按当前菜单测算 10 个主销 SKU 的单杯原料成本与毛利。  
3. 用近 14 天真实杯量回推是否达到盈亏平衡，并设定未来 30 天目标杯量。  
4. 与 2–3 家原料商询价，对比账期与起订量。  
5. 单独核算外卖订单的单杯净利，决定是否收缩平台活动。
