# 餐饮创业政策准入与合规要点

> 适用场景：创业模拟 · 环境 Agent / 政策维度  
> 知识类型：policy  
> 说明：内容为面向模拟的**常识级合规框架**，不同城市细则以当地市场监管与文旅部门公开信息为准；不构成法律意见。

---

## 1. 开办现制茶饮店的常见证照

开办一家现制奶茶/茶饮店，通常需要关注：

| 事项 | 说明 |
|------|------|
| 营业执照 | 主体资格；经营范围需覆盖餐饮服务或饮料制售等 |
| 食品经营许可证 | 或「仅销售预包装食品」以外的现制现售许可，按地方改革可能并入「食品经营」登记 |
| 健康证 | 直接接触食品的从业人员需有效健康证明 |
| 消防与装修合规 | 铺位性质、消防验收或备案要求因物业与面积而异 |
| 环保与油烟 | 以茶饮为主通常压力小于中餐，但仍需符合物业与环保要求 |
| 外卖经营 | 平台入驻需证照齐全；部分地区对包装与环保有额外要求 |

环境 Agent 可将「证照是否齐备」「政策收紧/放松」作为状态或事件，影响开业时间与一次性合规成本。

---

## 2. 选址与物业相关政策因素

- **业态限制**：部分住宅底商、学校周边对餐饮业态有限制或间距要求。  
- **学校周边**：对高糖饮料、营销活动可能有倡导性或地方性约束，影响大学生客群店的打法。  
- **保证金与租金发票**：影响成本结构与报销；模拟中可简化为「合规成本」一次性或按年扣减。

---

## 3. 用工与社保

- 全日制员工的社保与劳动合同是常见合规成本来源。  
- 过度依赖「仅日结兼职、无合同」存在劳动争议风险，风险 Agent 可在「降本裁员」选项中体现潜在隐患。  
- 排班与超时规则影响人效模型，间接影响个人 Agent 的「节省人工」行动是否可持续。

---

## 4. 税收与小规模纳税人（概念级）

- 小微餐饮主体常见按小规模纳税人或地方简化征收方式处理，具体税率与优惠以当年政策为准。  
- 模拟中不必展开复杂税制，可用「税费占营收约 X%」作为环境参数。  
- 发票与进项管理影响进货渠道选择（能否从正规经销商取得发票）。

---

## 5. 补贴与扶持（模拟用抽象）

部分城市或区县对「首次创业」「带动就业」「特色街区」有申报类补贴或减免，但：

- 具有申请门槛、材料与时间成本；  
- 到账存在不确定性与滞后；  
- **不应作为主现金流假设**。

环境 Agent 若触发「地方消费券 / 创业补贴」类事件，应标注为一次性、概率性利好，而非稳态收入。

---

## 6. 食品安全与舆情风险

- 原料溯源、储存温度、过期管理是日常合规重点。  
- 一次公开的食品安全舆情可导致客流断崖，接近「黑天鹅」。  
- 风险模式：可将「食安事件」作为低概率、高冲击事件，写入风险传导链（客流下降 → 收入下降 → 现金紧张 → 关店压力）。

---

## 7. 对环境 Agent 的行动启示

环境 Agent 可选行动示例与世界状态影响：

| 行动 | 可能影响的世界状态 |
|------|-------------------|
| 政策收紧（检查加频） | 合规成本↑、开业延迟、短期关停风险 |
| 消费券 / 促消费政策 | 短期客流↑、客单价可能↓ |
| 行业整顿或准入提高 | 新竞品进入变慢，但存量合规压力↑ |
| 人口或商圈规划调整 | 长期客流基底变化 |
