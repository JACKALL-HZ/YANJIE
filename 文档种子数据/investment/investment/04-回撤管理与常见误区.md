# 回撤管理与常见投资误区

**来源**：综合市场观察、投教文章与行为金融常识整理  
**适用人群**：所有个人投资者  
**适用地区**：通用  

---

## 一、什么是回撤

- **最大回撤**：从最高点到最低点的最大跌幅。  
- 例：从1.0跌到0.8，回撤为20%；要回到1.0需要上涨25%。  
- 回撤越大，回本所需涨幅越高，心理与财务压力也越大。

**建议**：  
- 根据自身睡眠质量与资金性质，设定可接受的最大回撤（如整体组合10%–20%）。  
- 通过降低权益比例、分散、再均衡来控制组合回撤。

---

## 二、回撤管理实用方法

1. **事前**：用历史波动与最大回撤数据筛选产品；做压力测试。  
2. **仓位**：不把短期要用的钱投入高波动资产。  
3. **分散**：股、债、货币、少量另类，避免单一赛道集中。  
4. **再均衡**：涨多了的卖一点，跌多了的补一点（在目标比例内）。  
5. **纪律**：提前写好“什么情况下加减仓”，减少情绪决策。  
6. **避免杠杆**：杠杆会放大回撤，普通投资者一般不需要。

---

## 三、常见误区

| 误区 | 现实 |
|------|------|
| 只存银行最安全 | 利率下行+通胀会侵蚀购买力；理财已净值化 |
| 买了很多基金就是分散 | 若重仓同一风格/赛道，风险高度重叠 |
| R2/“固收+”不会亏 | 含权益或信用下沉时可能破净 |
| 业绩比较基准=预期收益 | 仅供参考，不保证 |
| 追热门赛道必赚 | 高估值+拥挤交易容易大幅回撤 |
| 亏损就补仓摊低成本 | 可能越补越深，需有逻辑与上限 |
| 短期涨跌证明能力 | 长期一致性与风险控制更重要 |
| 保本高收益产品 | 高度可疑，可能是违规或骗局 |

---

## 四、行为纪律建议

- 设定投资政策说明书（即使简单几条）：目标、期限、可接受回撤、再均衡规则。  
- 减少频繁查看账户（尤其是高波动阶段）。  
- 大涨大跌后先冷静，再对照原定计划行动。  
- 定期（如每年）回顾一次，而不是每天交易。
